# 🍎 사과 합 게임

8×8 격자에서 사과 숫자들을 직사각형으로 드래그해 선택하는 1분 게임입니다. 선택한 영역의 숫자 합이 10의 배수라면 선택한 숫자만큼 점수를 얻습니다. 숫자는 아래로 내려오고 빈칸은 새 숫자로 채워지며, 최고 점수를 새로 세우면 꽃가루 효과가 나타납니다.

## 게임 소개

제한 시간 안에 시작 칸과 끝 칸을 대각선 꼭짓점으로 삼아 직사각형 영역을 선택하세요. 영역 안의 빈칸은 제외하고, 남은 숫자의 합이 10, 20, 30 등의 배수면 유효합니다. 유효한 조합의 숫자 합이 점수가 됩니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript로 구현했습니다. 별도 패키지 설치나 빌드 과정 없이 실행할 수 있습니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 연 뒤 시작 버튼을 누르면 게임이 시작됩니다.

## 커스터마이징한 부분

8×8 보드, 1분 제한 시간, 10의 배수 규칙, 직사각형 드래그 선택, 사과 이미지 타일, 숫자 낙하·보충, 최고 점수 꽃가루 효과를 적용했습니다. 게임 화면은 `index.html`, `style.css`, `script.js`로 분리했습니다.
